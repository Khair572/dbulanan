# Data Bulanan Santri

Aplikasi web untuk menampilkan dan mengelola data bulanan santri dengan tampilan publik dan panel admin.

## Struktur

- `index.html` — halaman publik data santri.
- `admin/login.html` — login admin.
- `admin/admin.html` — panel pengelolaan data.
- `theme.js` — mode terang dan gelap.
- `supabase-setup.sql` — struktur tabel dan kebijakan Supabase.

## Konfigurasi

Sesuaikan koneksi Supabase pada halaman aplikasi sebelum deployment. Detail struktur database tersedia pada `supabase-setup.sql`.

## Deployment

Project ini dapat disajikan sebagai website statis pada hosting yang mendukung HTML, CSS, dan JavaScript. Pastikan konfigurasi Supabase sudah sesuai sebelum digunakan.
